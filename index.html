CLOUD SYNC Rclone

계정 소유자가 자신의 Windows PC와 Google Drive, Microsoft OneDrive 사이에서 지정한 폴더를 동기화하는 개인용 도구입니다.

파일 전송에는 오픈 소스 프로그램 rclone을 사용합니다. 프로그램은 계정 소유자의 PC에서 실행되며, 이 안내 웹사이트에서는 파일 업로드나 로그인 기능을 제공하지 않습니다.

GoogleDrive 폴더는 Google Drive에, OneDrive 폴더는 Microsoft OneDrive에 연결합니다. SYNC 폴더는 PC를 통해 두 서비스에 순서대로 동기화합니다. 사용자가 선택한 폴더의 파일 생성, 수정, 삭제를 양방향으로 반영합니다.

본인 계정에서만 사용하는 도구이며 일반 이용자에게 서비스로 제공하지 않습니다. Google 또는 Microsoft가 제작하거나 보증하는 앱은 아닙니다.
