목적과 처리하는 정보

이 앱은 계정 소유자 개인의 폴더 동기화용 도구입니다. 사용자가 지정한 폴더의 파일 내용, 파일명, 폴더 구조, 크기 및 수정 시각을 읽고 전송합니다. Google 및 Microsoft 계정에 접근하기 위해 OAuth 인증 정보를 사용합니다.

Google Drive 권한

rclone이 기존 폴더와 파일을 읽고 쓰며 변경사항을 동기화하도록 Google Drive 파일 접근 권한을 요청합니다. 계정 소유자의 설정은 지정한 동기화 폴더로 작업 범위를 제한합니다. Google 비밀번호를 앱에 입력하거나 보관하지 않습니다.

저장과 전송

프로그램과 OAuth 인증 정보는 계정 소유자의 PC에 보관됩니다. 파일은 해당 PC와 사용자가 연결한 Google Drive 및 Microsoft OneDrive 사이에서 전송됩니다. 공통 SYNC 폴더는 두 클라우드에 복제됩니다. 동기화 상태와 충돌 파일, 삭제·덮어쓰기 복구용 백업이 PC 또는 지정된 클라우드 백업 폴더에 남을 수 있습니다.

사용 제한

Google API에서 받은 정보는 요청한 파일 동기화와 복구 목적으로만 사용합니다. 광고, 판매, 사용자 프로파일링 또는 AI 모델 학습에 사용하지 않습니다. 연결된 저장소 외의 제3자에게 파일이나 인증 정보를 제공하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한된 사용 요건을 준수합니다.

보관과 삭제

사용자는 Windows의 자동 실행 작업을 중지하고 Google 및 Microsoft 계정 설정에서 앱 접근 권한을 철회할 수 있습니다. 로컬 인증 파일과 동기화 상태, 클라우드 파일 및 백업은 사용자가 직접 관리하고 삭제할 수 있으며, 접근 권한 철회만으로 기존 파일과 백업이 자동 삭제되지는 않습니다.

이 안내 웹사이트

이 사이트 자체에는 로그인, 업로드, 분석 스크립트, 광고 또는 추적 쿠키가 없습니다. 사이트 호스팅 서비스인 GitHub Pages는 서비스 운영을 위해 자체 정책에 따라 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

문의

개인용 도구의 운영자는 연결된 Google 계정의 소유자입니다. 문의 연락처는 Google OAuth 동의 화면에 표시되는 사용자 지원 이메일입니다.
